# Miner's Gems

**Miner's Gems** is a 2D mining platformer made with Godot. Guide the miner through a rocky landscape, climb cliffs, avoid dangerous falls, and collect every crystal to complete the level.

## Features

- Hand-drawn miner, crystal, and cave artwork
- Platforming with running, jumping, and wall climbing
- Climb up and descend vertical rock faces
- Health system with damage from long falls
- Healing plants placed throughout the level
- Crystal collection progress and a level-complete screen
- Framed title screen with a controls guide

## Controls

| Key | Action |
| --- | --- |
| ← / → | Move left / right |
| ↑ | Climb up a wall |
| ↓ | Climb down a wall |
| Space | Jump or jump away from a wall |

## Objective

Collect all the crystals in the level. Watch your health: long falls cause damage, and healing plants restore health. The level-complete screen appears after the last crystal is collected.

## Run the game

1. Install [Godot Engine 4.7](https://godotengine.org/).
2. Clone or download this repository.
3. Open `project.godot` in Godot.
4. Press **F5** to run the project.

## Built with
